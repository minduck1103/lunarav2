# Assets

Các file PNG trong thư mục này thuộc **thiết kế ban đầu đã được thay thế** (Ktor, database và lưu lịch sử), giữ lại như tài liệu lịch sử, không dùng trong app:
- `system-architecture.png`: kiến trúc hệ thống mức cao.
- `reading-flow.png`: vòng đời một phiên Tarot reading.
- `domain-erd.png`: ERD khái niệm.

Không dùng chúng làm hướng dẫn triển khai. Kiến trúc hiện tại là React + Vercel Function, không database; xem [kiến trúc hiện tại](../docs/02-architecture.md), [API](../docs/06-database-and-api.md) và [luồng UI](../docs/07-frontend-ux.md).
